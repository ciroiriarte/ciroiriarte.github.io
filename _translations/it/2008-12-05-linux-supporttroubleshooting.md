Trattando con il supporto Linux di Novell ho scoperto il loro script supportconfig, davvero utile per fare troubleshooting dei sistemi da remoto (o in sede :D).

In pratica è uno script bash che raccoglie dati su un sistema linux (è stato fatto per SLES, ma dovrebbe funzionare con qualsiasi linux). Il risultato è un bel tarball che puoi portarti via per analizzare il sistema altrove.

Il software: http://www.novell.com/communities/node/2332/supportconfig-linux  
Guida di base al controllo dello stato del server: http://www.novell.com/communities/node/4097/basic-server-health-check-supportconfig
