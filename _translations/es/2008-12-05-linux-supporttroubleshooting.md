Tratando con el soporte de Novell para Linux descubrí su script supportconfig, que es realmente útil para resolver problemas de sistemas de forma remota (o en sitio :D).

Es básicamente un script bash que recolecta datos de un sistema linux (fue hecho para SLES, pero debería funcionar con cualquier linux). El resultado es un tarball que puedes llevarte para analizar el sistema fuera del sitio.

El software: http://www.novell.com/communities/node/2332/supportconfig-linux  
Guía básica de chequeo de salud: http://www.novell.com/communities/node/4097/basic-server-health-check-supportconfig
