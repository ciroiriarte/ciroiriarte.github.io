Lidando com o suporte Linux da Novell, descobri o script supportconfig deles, que é muito útil para fazer troubleshooting de sistemas remotamente (ou no local :D).

Basicamente é um script bash que coleta dados de um sistema linux (foi feito para SLES, mas deveria funcionar com qualquer linux). O resultado é um tarball bacana que você pode levar com você para analisar o sistema fora do local.

O software: http://www.novell.com/communities/node/2332/supportconfig-linux  
Guia básico de verificação de saúde: http://www.novell.com/communities/node/4097/basic-server-health-check-supportconfig
